Granular RBAC and immutable audit logging protect venue operations

Granular RolesAdmin · Staff · Gate

Role-Based Access Control isolates sensitive actions: only admins can block courts or refund money.

JWT AuthenticationStateless Security

Cryptographically signed bearer tokens protect all API endpoints with automatic session expiry.

Audit Activity Logpages/activity.tsx

Every mutation (approvals, cancellations, slot holds) is logged with user identity, timestamp & IP.

Input SanitizationAnti-Injection Shield

Strict DTO validation in ASP.NET Core prevents SQL injection, XSS, and parameter tampering.
